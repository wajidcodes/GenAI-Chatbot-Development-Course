# Lecture 10 — PostgreSQL Database Fundamentals

## Overview

This lecture introduced databases and PostgreSQL. It covered why applications need databases, common database types, basic SQL commands, and a practical To-Do list task using Neon PostgreSQL.

## Topics Covered

- What a database is
- Why databases are needed
- Types of databases
- PostgreSQL and relational databases
- Tables, rows, columns, and primary keys
- Basic SQL commands: `CREATE TABLE`, `INSERT`, `SELECT`, `DELETE`, and `DROP TABLE`
- Creating a cloud PostgreSQL database with Neon
- Building a To-Do list data table
