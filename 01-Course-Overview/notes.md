# Lecture 1 Notes — Course Overview

## 1. Course Introduction

The GenAI and Chatbot Development course covers the skills needed to build chatbot and AI-related applications. The first part of the course focuses on web development basics, which form a foundation for later work.

## 2. Course Objectives

The course aims to teach:

- Web development fundamentals (HTML, CSS, and related tools)
- Skills that will later support chatbot and GenAI application development
- Practical implementation through lectures and exercises

## 3. What We Will Learn

Based on the course introduction, the learning path includes:

- Building blocks of web pages (HTML and CSS)
- Layout and styling techniques
- Later topics related to chatbots and generative AI (to be covered as the course progresses)

## 4. Course Direction

The course starts with standard web development topics because chatbots and AI interfaces often run in browsers or depend on web technologies. Understanding HTML and CSS first makes it easier to work with front-end interfaces and integrations later in the course.

## 5. Important Points

- This lecture was an overview — no coding exercises were assigned for this folder.
- Lecture materials are organized by number in separate folders (e.g., `02-HTML-Fundamentals`, `03-HTML-Elements`).
- Practice files and notes will be added to each lecture folder as the course continues.

## 6. Common Mistakes

- Assuming the course jumps straight into AI tools without web fundamentals — the early lectures deliberately build that foundation first.
- Not keeping lecture notes organized — using each folder's `README.md` and `notes.md` helps when revising later.
