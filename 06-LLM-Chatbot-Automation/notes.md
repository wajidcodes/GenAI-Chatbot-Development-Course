# 1. JavaScript History

## Netscape

JavaScript was originally developed for web browsers.

Netscape played an important role in the early development of JavaScript.

---

## Brendan Eich

**Brendan Eich** created the first version of JavaScript while working at Netscape.

The language was developed very quickly because Netscape wanted a scripting language for web browsers.
