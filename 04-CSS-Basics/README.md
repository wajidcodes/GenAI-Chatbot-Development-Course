# Lecture 4 — CSS Basics

## Overview

This lecture introduced CSS (Cascading Style Sheets) and how to apply styles to HTML elements. I practiced the three ways to add CSS, common selectors, text and box styling, form element styling, and a brief introduction to Flexbox for a navigation bar layout.

## Topics Covered

### Types of CSS

- Inline CSS
- Internal CSS (inside `<style>` in `<head>`)
- External CSS (linked `.css` file)

### CSS Selectors

- Universal selector (`*`)
- Element selectors
- ID selectors (`#id`)
- Class selectors (`.class`)

### Text Styling

- `color`, `font-size`, `font-weight`, `font-style`
- `text-align`, `letter-spacing`, `text-decoration`

### Borders and Box Styling

- Border width, color, and style
- `border`, `border-radius`
- `width`, `height`, `background-color`, `padding`

### Form and Button Styling

- Input field styling
- Button styling with background, borders, padding, and font properties

### Basic Flexbox Introduction

- `display: flex`
- `align-items`, `justify-content`, `gap`
- Simple navigation bar layout
