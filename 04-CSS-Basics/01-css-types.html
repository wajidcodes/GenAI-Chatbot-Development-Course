Types of CSS

CSS can be added to an HTML document in three different ways: Inline CSS, Internal CSS, and External CSS.

1. Inline CSS

This paragraph is styled using Inline CSS.

Inline CSS is written directly inside the style attribute of an HTML element.

2. Internal CSS

This paragraph is styled using Internal CSS.

Internal CSS is written inside the <style> element in the <head> section.

3. External CSS

This paragraph is styled using External CSS.

External CSS is written in a separate .css file and connected to HTML using the <link> element.

Comparison

  • Inline CSS: Written directly inside an HTML element.
  • Internal CSS: Written inside the <style> element.
  • External CSS: Written in a separate CSS file.
