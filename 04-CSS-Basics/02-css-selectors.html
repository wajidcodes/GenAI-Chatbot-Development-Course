CSS Selectors

CSS selectors are used to select HTML elements that we want to style.

1. Universal Selector

The universal selector is represented by an asterisk (*) and selects all HTML elements.

An element selector selects HTML elements by their tag name.

An ID selector uses the # symbol followed by the ID name.
