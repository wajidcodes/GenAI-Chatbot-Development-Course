# Lecture 9 — n8n Email Attachment & Data Automation Revision

## Overview

This lecture revised the email attachment and data automation workflow introduced in Lecture 8. The focus was on confidently tracing data from an incoming email attachment through extraction, spreadsheet reading, record processing, conditions, and automated email actions.

## Topics Covered

- Email triggers and attachments in n8n
- Binary file data
- Reading XLSX/Excel files into workflow records
- Processing multiple records
- Loops and item-by-item processing
- Conditions and the Switch node
- Using values from previous nodes
- Sending emails based on record data
- Testing and troubleshooting workflow paths
