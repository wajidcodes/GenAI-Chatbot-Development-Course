# Lecture 5 — CSS Flexbox

## Overview

This lecture revised previous CSS concepts and introduced CSS Flexbox in more depth. I practiced creating flex containers, aligning items, changing direction, adding spacing, and combining multiple Flexbox properties.

## Topics Covered

- Flex containers and flex items
- `display: flex`
- `justify-content` (`center`, `flex-start`, `flex-end`)
- `align-items` (`center`)
- `flex-direction` (`row`, `row-reverse`, `column`)
- `gap`
- `flex-wrap` (`wrap`)
- Centering and aligning content inside boxes
- Combining multiple Flexbox properties
