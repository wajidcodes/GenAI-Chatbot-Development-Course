# Lecture 2 — HTML Fundamentals

## Overview

This lecture introduced the basic structure of an HTML document and commonly used HTML tags for text, formatting, and lists. I practiced building a single page that demonstrates each tag group in separate sections.

## Topics Covered

- Basic HTML document structure (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`, `<title>`)
- Meta tags (`charset`, `viewport`)
- Headings (`<h1>` through `<h6>`)
- Paragraphs (`<p>`) and line breaks (`<br>`)
- Text formatting tags (`<b>`, `<strong>`, `<i>`, `<em>`, `<u>`, `<mark>`, `<small>`, `<del>`, `<ins>`)
- Superscript and subscript (`<sup>`, `<sub>`)
- Inline and block elements (`<span>`, `<div>`)
- Ordered lists (`<ol>`), unordered lists (`<ul>`), and list items (`<li>`)
- Nested lists
- HTML comments and horizontal rules (`<hr>`)
