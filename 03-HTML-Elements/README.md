# Lecture 3 — HTML Tables, Images, Videos & Links

## Overview

This lecture covered additional HTML elements for displaying structured data, images, videos, and hyperlinks on a web page. I practiced each topic in separate HTML files with numbered examples.

## Topics Covered

### Tables

- Table structure: `<table>`, `<tr>`, `<th>`, `<td>`
- Table attributes: `border`, `cellpadding`, `cellspacing`
- Spanning cells: `colspan`, `rowspan`

### Images

- The `<img>` tag
- Local and online images
- Attributes: `src`, `alt`, `width`, `height`, `title`
- Clickable images using `<a>` and `<img>`
- Multiple images and missing-image fallback

### Videos

- The `<video>` and `<source>` tags
- Attributes: `controls`, `autoplay`, `muted`, `loop`, `poster`, `width`, `height`
- Multiple video sources and fallback text

### Links

- The `<a>` (anchor) tag
- The `href` attribute
- External links and `target="_blank"`
- Local page links and same-page anchors (`#id`)
- Email links (`mailto:`)
- The `title` attribute
