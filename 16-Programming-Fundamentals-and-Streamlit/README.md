# Lecture 16 — Programming Fundamentals & Streamlit

## Overview

This lecture introduced core programming concepts: variables, data types, strings, numbers, and functions. Built-in functions were introduced generally through the example of `print()`. It also introduced Streamlit, a Python framework for building simple interactive web applications.

## Topics Covered

- Programming fundamentals
- Variables
- Strings and numbers
- Basic data types
- Functions
- Parameters and return values
- General introduction to built-in functions
- Introduction to Streamlit
- Building a simple Streamlit application

After this lecture, I can use variables and simple data types, explain the general structure of a function, and understand how Streamlit turns Python code into an interactive web app.
